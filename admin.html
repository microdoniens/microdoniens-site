3
Nom du repo GitHub
4
URL du site en ligne
5
Mot de passe admin (optionnel, remplace "microdoniens")

🔒 Sécurité

Mot de passe admin Laisse vide pour garder "microdoniens"

🌐 GitHub Pages / Netlify

Comment connecter Netlify au repo : 1. Crée un compte sur netlify.com (gratuit)
2. Clique "Add new site" → "Import from Git"
3. Connecte ton compte GitHub et sélectionne le repo
4. Paramètres de build : laisse vide (site statique)
5. Netlify te donne une URL automatiquement

À chaque fois que Claude publie, le site se met à jour en ~30 secondes.
